About the Application

YouTube Shorts Autopilot Desktop FitIn60s is a desktop application intended to simplify supported YouTube video-uploading and scheduling workflows.

The application runs on the user's computer and uses Google OAuth authorization to access the YouTube functionality permitted by the user.

Features

Video Uploading

Upload user-selected video files to an authorized YouTube channel.

Video Metadata

Submit supported information such as video titles, descriptions, and publication settings.

Scheduling

Configure video publication schedules where supported by the application and YouTube.

Google Authorization

Use Google's authorization process to grant the permissions required for supported features.
